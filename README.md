# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

源提示词摘要：面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；支持时长重算、硬时间风险、突发插播、角色权限、操作历史、一键撤回和断网应急队列。

## 技术栈

React19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next、date-fns、dnd-kit。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62011

## 双终端协同与断网恢复流程

- **同时编辑 / 断网合并**：导播台（1 号终端）与主编台（2 号终端）可在顶栏切换，各自岗位偏好与应急队列独立持久化。直播开始后两台终端同时编辑同一张串联单，断网期间排片本地落地，恢复后合并。
- **先改优先（字段级）**：每个可编辑字段记录 `fieldTs/fieldOwner`，合并时同字段先到的修改保留，后到修改记入“冲突拦截”而不是覆盖；同一终端可继续修改自己持有的字段。
- **已播出锁定**：一旦标记“已播出”，取消、改时长等任何后到操作都不能覆盖该状态。
- **时长变化 → 风险重算**：合并后总时长一旦变化，原硬时间风险结论立即失效并按新排片重新计算（风险轮次 +1），风险数与收播时间实时展示。
- **应急队列只提交未落地操作**：突发插播、取消、顺序调整全部结构化为带 ID 的 op 进队列；服务端保存幂等日志，重复恢复不会重复插入、不会重复追加突发记录。
- **岗位权限**：导播可排片/插播/取消；主编可排片但不能插播/取消；演播室只能标记已播出；字幕无任何串联单写权限。越权操作在 Redux 数据层直接拒绝、全局提示并留痕（协同恢复页可查）。
- **旧数据升级**：无字段时间戳的旧串联单自动补齐开播前基线，升级后继续可用；新增导航页「协同恢复」可模拟对端排片、断网/恢复并查看合并报告与权限矩阵。
